# プロダクトコンテキスト

## このプロジェクトが存在する理由

このプロジェクトは、テキストを高品質な音声に変換するリアルタイム音声合成システムを提供することを目的としています。Cartesia API を活用し、PCM ストリーミング再生、文単位でのインテリジェントな処理を実現します。特に、遅延を最小限に抑えたリアルタイム体験と、自然な日本語音声合成を両立させることに焦点を当てています。

## 解決する問題

1. **リアルタイム音声合成の技術的複雑さの解決**: PCM ストリーミング、文単位処理などの高度な音声技術を、シンプルな API インターフェースで利用可能にします。

2. **遅延のない自然な音声体験の実現**: 文単位での並列処理とストリーミング配信により、長文でも待ち時間なく自然な音声再生を提供します。

3. **PCMストリーミングによる低遅延音声配信**: リアルタイムPCMストリーミングにより、様々なユースケースに対応します。

4. **インテリジェントなテキスト処理**: GINZA NLPライブラリによる高精度な文分割と、文単位での並列音声生成により、自然な読み上げを実現します。

5. **堅牢なマルチプラットフォーム対応**: FastAPI ベースの RESTful API とモダンな React フロントエンドにより、様々な環境からのアクセスを支援します。

## どのように機能するべきか

1. **PCMストリーミング音声配信**:

   - **PCMストリーミング**: リアルタイム低遅延再生（デフォルト推奨）
   - **PCMバイト**: 直接音声データ取得

2. **インテリジェントなテキスト処理パイプライン**:

   - GINZA NLPによる高精度文分割
   - 文単位での並列音声生成
   - 自然な読み上げフローの実現

3. **リアルタイムストリーミングアーキテクチャ**:

   - WebSocketベースの双方向通信
   - チャンク単位でのリアルタイム配信
   - AudioContextによる無音間隙のない連続再生

4. **高品質音声フォーマット対応**:

   - 48kHz PCM s16le 標準対応
   - 高性能音声処理

5. **モジュール化された拡張可能設計**:

   - サービス層での機能分離（TTS、Audio、Text、Streaming）
   - 認証システムの統合
   - 新機能追加への高い対応力

6. **堅牢なエラーハンドリングとリソース管理**:
   - 自動ファイルクリーンアップ
   - ストリーミング中断対応
   - 詳細なログ記録とデバッグ支援

## ユーザー体験の目標

1. **ゼロ遅延感のリアルタイム体験**:

   - PCMストリーミングによる即座の音声開始
   - 文単位処理による自然な読み上げフロー
   - ユーザーを全く待たせない即応性

2. **直感的で美しいインターフェース**:

   - Material-UI による洗練されたデザイン
   - 3つの音声形式を簡単に切り替え可能
   - リアルタイム状態表示とフィードバック

3. **高い信頼性と透明性**:

   - 詳細なエラーメッセージとデバッグ情報
   - ストリーミング状況の可視化
   - 一貫した API レスポンス

4. **柔軟な利用シナリオ対応**:

   - 即時再生（PCMストリーミング）
   - データ取得（PCMバイト）
   - バッチ処理から対話的利用まで

5. **開発者フレンドリーな設計**:
   - OpenAPI 仕様による明確な API ドキュメント
   - 認証システムの統合
   - 複数の統合方法（REST API、WebSocket）

## 技術的な価値提案

1. **業界標準の音声品質**: 48kHz PCM による高品質音声
2. **スケーラブルなアーキテクチャ**: モジュール化設計による高い拡張性
3. **最新技術スタックの活用**: FastAPI、React、GINZA NLP
4. **プロダクション対応**: 認証、ログ、エラーハンドリング、リソース管理の完備
