# アクティブコンテキスト

## 現在の作業の焦点

このプロジェクト「テキスト読み上げ API サーバー」は、Cartesia API を利用したテキスト読み上げ機能を RESTful API として提供するサービスの開発です。現在の焦点は以下の通りです：

1. **PCM専用API エンドポイントの機能実装**

   - PCM s16le ストリーミング配信機能（`/tts/stream`）
   - PCMバイナリデータ直接取得機能（`/tts/bytes`）
   - 音声キャッシュ統計情報取得（`/tts/cache/stats`）
   - 音声キャッシュクリーンアップ（`/tts/cache/cleanup`）

2. **音声キャッシュシステムの実装**

   - SQLiteベースの高速音声キャッシュ
   - テキスト+パラメータのハッシュベースキー
   - 同一テキストの音声合成再利用による高速化
   - 自動的な古いエントリ削除機能

3. **高品質音声処理の最適化**

   - 文単位での音声合成による自然な読み上げ
   - GINZA（日本語NLP）による高精度な文分割
   - PCM s16le形式でのリアルタイムストリーミング

3. **認証システムとセキュリティ**

   - APIキー認証システムの実装
   - 開発環境での認証スキップ機能
   - 入力バリデーションとエラーハンドリング

4. **モジュール化されたアーキテクチャ**
   - サービス層の分離（audio_service, streaming_service, text_service, voice_cache_service）
   - ルーター層の分離（tts_router）
   - ユーティリティ層の分離（file_utils）
   - キャッシュサービスの統合実装

## アクティブな決定事項と考慮事項

### 現在の決定事項

1. **ファイル保存とストリーミング方式**

   - PCMストリーミングはリアルタイム配信（保存なし）
   - デバッグ用PCMファイルの自動生成と保存
   - パス: `temp_audio/` ディレクトリ

2. **音声フォーマットとパラメータ**

   - PCM形式：s16le、48kHz、16bit、モノラル
   - デフォルト声 ID: `2334b692-d045-48b5-ac45-d7bf5785026f`
   - デフォルト言語: 日本語（ja）
   - 速度オプション: slow, normal, fast

3. **認証とセキュリティ**

   - APIキー認証（X-API-Keyヘッダー）
   - 開発環境での認証スキップ
   - 環境変数での認証設定管理

4. **インフラ構成**

   - FastAPI + Uvicorn
   - PostgreSQL（将来的なデータ永続化用）
   - docker-compose による環境構築
   - AVライブラリによる音声処理

5. **文処理とNLP**

   - GINZA（ja_ginza_electra）による日本語文分割
   - シンプルな正規表現による代替文分割
   - 文間の自動ポーズ挿入（0.2秒）

6. **フロントエンドの位置付け**
   - Next.js によるフロントエンドはテスト用途が主目的
   - GitHub UI を参考にしたテーマデザインを採用予定
   - API 機能検証と簡易的なユーザーインターフェース提供
