# システム全体サマリー

## プロジェクト概要

**リアルタイム音声合成システム** - PCM専用の高品質音声配信プラットフォーム + 音声キャッシュシステム

- **主な機能**: 2つの音声配信方式（PCMストリーミング、PCMバイト取得）+ 音声キャッシュ
- **技術特徴**: 文単位並列処理、リアルタイムストリーミング、GINZA NLP統合、SQLite音声キャッシュ
- **品質基準**: 48kHz PCM s16le、放送レベル音質、高速キャッシュ再利用
- **開発段階**: βステージ（プロダクション準備段階）

## API エンドポイント

### 1. PCM ストリーミング（推奨デフォルト）

- **エンドポイント**: `POST /api/tts/stream-pcm`
- **用途**: リアルタイム低遅延音声再生
- **特徴**: WebSocket、チャンク配信、AudioContext統合

### 2. PCM バイト取得

- **エンドポイント**: `POST /api/tts/pcm-bytes`
- **用途**: 直接音声データアクセス
- **特徴**: Raw PCMデータ、カスタム処理対応
